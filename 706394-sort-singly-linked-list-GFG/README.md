# [Sort Singly Linked List](https://www.geeksforgeeks.org/problems/insertion-sort-for-singly-linked-list/1)
## Medium
Given a singly linked list, sort the list in ascending order.
Examples:
Input: head: 30-&gt;23-&gt;28-&gt;30-&gt;11-&gt;14-&gt;19-&gt;16-&gt;21-&gt;25 
Output: 11-&gt;14-&gt;16-&gt;19-&gt;21-&gt;23-&gt;25-&gt;28-&gt;30-&gt;30 Explanation: The resultant linked list is sorted.
Input: head: 19-&gt;20-&gt;16-&gt;24-&gt;12-&gt;29-&gt;30 
Output: 12-&gt;16-&gt;19-&gt;20-&gt;24-&gt;29-&gt;30Explanation: The resultant linked list is sorted.
Constraints:
0 ≤ number of nodes ≤ 103
0 ≤ node-&gt;data ≤ 104
