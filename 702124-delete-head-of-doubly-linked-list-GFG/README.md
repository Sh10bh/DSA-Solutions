# [Delete Head of Doubly Linked List](https://www.geeksforgeeks.org/problems/delete-head-of-doubly-linked-list/1)
## Easy
Given the head of a doubly linked list, delete the head node and return the new head of the list.
Examples :
Input:Output: 2 &lt;-&gt; 3Explanation: The first node [1] is removed, and the next node [2] becomes the new head.
Input: head = [2, 5, 7, 8, 99, 100] Output: 5 &lt;-&gt; 7 &lt;-&gt; 8 &lt;-&gt; 99 &lt;-&gt; 100Explanation: The head node [2] is deleted, and the remaining list starts from node 5.
Constraints:2 ≤ number of nodes ≤ 1051 ≤ node-&gt;data ≤ 109
